# WildVision AI

Independent Android wildlife photography assistant project.

This directory is a scaffold in the GPT-OS repository. The AppCreator24 wrapper creates content-based app sections, not native Android source code. Native camera and ML features must be built in an Android project.

## Planned modules
- CameraX preview and capture
- Camera2 capability inspection and manual controls where supported
- Local image pipeline
- ONNX Runtime model integration
- Optional HTTPS backend for heavier enhancement and species suggestions

## Safety and scientific integrity
- Preserve original photographs.
- Clearly label AI-generated enhancement.
- Treat species matches as suggestions, not confirmed identifications.
- Do not publish precise locations of sensitive wildlife.
